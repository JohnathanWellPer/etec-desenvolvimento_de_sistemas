## Study Context

> This project serves as a foundational artifact in Agile Project Management and Systems Analysis. It demonstrates how to translate an abstract software idea into a structured Agile Vision Document, defining the core problem, stakeholders, business constraints, and United Nations Sustainable Development Goals (SDGs). It acts as a professional blueprint for a solo developer to execute a Minimum Viable Product (MVP).

<br/>

## The Application

The "TechRecycle Vision Document" is a structured Markdown artifact that outlines the architecture, scope, and user stories for an e-waste reverse logistics platform. It specifies the requirements for connecting IT companies looking to sustainably dispose of hardware with NGOs in need of technology.

<br/>

## Business Rules (Applied Logic)

1. **Scrum of One Framework:** The document adapts standard Scrum roles (Product Owner, Scrum Master, Development Team) into a streamlined "Scrum of One" context, optimizing Agile ceremonies for solo portfolio development.
2. **ESG & SDG Integration:** The project scope explicitly aligns the software's deliverables with global sustainability metrics, specifically targeting UN SDG 12 (Responsible Consumption and Production) and SDG 4 (Quality Education).

<br/>

## How to Run (Local Deploy)

1. Clone this repository to your local environment.
2. Open the directory in your preferred code editor (e.g., Notepad++).
3. Open the `vision_document.md` file to review the Agile planning constraints and user stories.
4. Render the Markdown file using any standard viewer or directly on GitHub.

## Contexto do Estudo

> Este projeto atua como um artefato fundamental em Gestão Ágil de Projetos e Análise de Sistemas. Ele demonstra como traduzir uma ideia abstrata de software em um Documento de Visão Ágil estruturado, definindo o problema central, stakeholders, restrições de negócio e os Objetivos de Desenvolvimento Sustentável (ODS) da ONU. Funciona como um projeto profissional para um desenvolvedor solo executar um Produto Mínimo Viável (MVP).

<br/>

## A Aplicação

O "Documento de Visão TechRecycle" é um artefato estruturado em Markdown que delineia a arquitetura, o escopo e as histórias de usuário para uma plataforma de logística reversa de lixo eletrônico (e-waste). Ele especifica os requisitos para conectar empresas de TI que buscam descartar hardware de forma sustentável com ONGs que necessitam de tecnologia.

<br/>

## Regras de Negócio (Lógica Aplicada)

1. **Framework Scrum of One:** O documento adapta os papéis padrão do Scrum (Product Owner, Scrum Master, Equipe de Desenvolvimento) para um contexto enxuto de "Scrum of One", otimizando as cerimônias ágeis para o desenvolvimento solo de portfólio.
2. **Integração ESG e ODS:** O escopo do projeto alinha explicitamente as entregas do software com métricas globais de sustentabilidade, focando especificamente no ODS 12 (Consumo e Produção Responsáveis) e ODS 4 (Educação de Qualidade) da ONU.

<br/>

## Como Executar (Deploy Local)

1. Faça o clone deste repositório para o seu ambiente local.
2. Abra o diretório no seu editor de código preferido (ex: Notepad++).
3. Abra o arquivo `vision_document.md` para revisar as restrições de planejamento ágil e as histórias de usuário.
4. Renderize o arquivo Markdown usando qualquer visualizador padrão ou diretamente no GitHub.
