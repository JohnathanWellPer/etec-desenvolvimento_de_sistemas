## Study Context

> This project elevates basic English language concepts into a practical corporate tool. Instead of simply studying greetings, personal pronouns, and the Simple Present tense theoretically, this application integrates them into a programmatic solution designed to assist IT professionals in drafting grammatically correct international business emails.

<br/>

## The Application

The "Corporate Mailer" is a PHP-driven web interface that automates the creation of professional English emails. Users input the recipient's name, select the time of day or formality level, and define the subject. The server-side logic processes these inputs to generate a ready-to-copy email body formatted in a custom Dark Mode UI.

<br/>

## Business Rules (Applied Logic)

1. **Dynamic Greeting Selection:** A server-side `switch/case` structure evaluates the user's selection (morning, afternoon, evening, formal, or informal) and automatically concatenates the correct English greeting with the recipient's name.
2. **Grammar Enforcement:** The generated email body strictly applies the Simple Present tense and correct personal/object pronouns (e.g., "I hope you are doing well", "I am writing..."), ensuring the output aligns with standard corporate communication guidelines.

<br/>

## How to Run (Local Deploy)

1. Start the **Apache** service in your XAMPP Control Panel.
2. Clone this repository into the Apache root folder (`htdocs`).
3. Access `http://localhost/[repository_path]/index.php` in your web browser.
4. Fill out the form fields and click "GENERATE E-MAIL" to view the output.

## Contexto do Estudo

> Este projeto eleva conceitos básicos da língua inglesa a uma ferramenta corporativa prática. Em vez de estudar saudações, pronomes pessoais e o tempo verbal Simple Present apenas de forma teórica, esta aplicação integra esses elementos em uma solução programática desenvolvida para auxiliar profissionais de TI na redação de e-mails comerciais internacionais gramaticalmente corretos.

<br/>

## A Aplicação

O "Corporate Mailer" é uma interface web orientada a PHP que automatiza a criação de e-mails profissionais em inglês. Os usuários inserem o nome do destinatário, selecionam o período do dia ou o nível de formalidade e definem o assunto. A lógica no lado do servidor processa essas entradas para gerar o corpo de um e-mail pronto para cópia, formatado em uma UI customizada em Dark Mode.

<br/>

## Regras de Negócio (Lógica Aplicada)

1. **Seleção Dinâmica de Saudação:** Uma estrutura `switch/case` no servidor avalia a seleção do usuário (manhã, tarde, noite, formal ou informal) e concatena automaticamente a saudação correta em inglês com o nome do destinatário.
2. **Aplicação de Regras Gramaticais:** O corpo do e-mail gerado aplica estritamente o tempo verbal Simple Present e os pronomes pessoais/objetos corretos (ex: "I hope you are doing well", "I am writing..."), garantindo que o resultado esteja alinhado com as diretrizes padrão de comunicação corporativa.

<br/>

## Como Executar (Deploy Local)

1. Inicie o serviço **Apache** no seu XAMPP Control Panel.
2. Faça o clone deste repositório na pasta raiz do Apache (`htdocs`).
3. Acesse `http://localhost/[caminho_do_repositorio]/index.php` no seu navegador web.
4. Preencha os campos do formulário e clique em "GENERATE E-MAIL" para visualizar o resultado.
